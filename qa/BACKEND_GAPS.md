## 3. Not gaps: decisions that belong to the owner

- Switch on NAFNet, CodeFormer and GFPGAN (BG-07) and accept their non-commercial licences for the defence.
- Approve the semantic-search model, or leave the feature off (BG-11).
- Whether the cloud advisor is ever switched on: it needs a paid key, its own consent, and has never run against a real provider.
- Which host runs the backend (BG-10): shared hosting cannot run Python with PyTorch; a VPS can.

## 4. Order to send them (the defence is on 2026-11-10)
